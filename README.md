**API Automation with RestAssured**

This repository contains a framework for API automation testing for the Restful-booker API, built using Java and RestAssured.

**Overview**

This project is an API automation framework designed to test the functionalities of the Restful-booker API. It includes tests for Create, Read, Update, and Delete (CRUD) operations on the booking information.

**Features**

Tests for all major API endpoints of Restful-booker.

A scalable and maintainable framework structure.

Use of POJOs (Plain Old Java Objects) for request and response handling.

Data-driven testing capabilities.

Detailed logging for easy debugging.

**Technologies Used**

Java: Core programming language.

RestAssured: For simplifying API testing in Java.

TestNG: As the testing framework for managing and running tests.

Maven: For project and dependency management.

Reporting : Allure
